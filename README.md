# Portfólio - João Gabriel

Portfólio profissional desenvolvido para a disciplina de Projeto de Software / Laboratório de Desenvolvimento de Software da PUC Minas.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Font Awesome e Google Fonts
- GitHub API para listar repositórios públicos recentes
- FormSubmit para envio do formulário de contato

## Funcionalidades

- Layout responsivo
- Temas claro e escuro
- Conteúdo em português e inglês
- Projetos recentes carregados pelo GitHub
- Currículo em PDF em PT-BR e EN-US
- Formulário de contato

## Execução

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
